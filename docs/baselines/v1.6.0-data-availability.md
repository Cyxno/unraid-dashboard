# Beacon v1.6.0 — Fase 0 Data Availability Matrix

Vastgelegd 2026-10-08 ~21:50 UTC op de v1.5.1-baseline (07a8e82), vóór enige
implementatie. Prometheus draait met default TSDB-retention (15 dagen,
30s scrape-interval); geen expliciete retention-flag.

Consequenties voor het ontwerp:

1. **Prometheus is de trendbron** — Beacon dupliceert die historie niet
   (Fase 21). 24h/7d zijn eersteklas; **30d is structureel "insufficient
   history"** op deze installatie (TSDB-retention 15d) en wordt pas
   aangeboden als retention dat toelaat (capability-check per query).
2. Incident-retentie wordt verhoogd naar **30d / cap 500** (bounded) zodat
   7d-recurrence betekenisvol wordt; dit is additief en blijft binnen de
   bestaande `/app/data`-architectuur.
3. Bron-latencies krijgen een kleine **in-memory ring** (bounded) en
   starten bewust als "insufficient history".
4. Update-impact start als "insufficient history" en wordt automatisch
   betekenisvol zodra de update-machine draait.
